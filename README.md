# Personal Portfolio — Full Stack Development Assignment

A responsive and accessible personal portfolio created for the Full Stack Development assignment.

## Technologies
- HTML5 semantic structure
- CSS3 custom responsive styling
- Bootstrap 5 grid, navbar, buttons and responsive utilities
- JavaScript ES6+
- Bootstrap Icons

## Implemented Requirements

### 1. HTML5 Structure
Semantic sections:
- Home
- About
- Education
- Skills
- Projects
- Achievements
- Contact

Also includes headings, paragraphs, lists/tags, links, form controls and accessible labels.

### 2. CSS3 & Responsive Design
- CSS variables
- Box model
- Typography
- Flexbox/Grid through Bootstrap and custom CSS
- Mobile-first responsive breakpoints
- Hover and transition effects
- Dark/light theme variables

### 3. Bootstrap UI
- Responsive navbar
- Bootstrap grid
- Responsive buttons
- Form components
- Responsive layout utilities
- Bootstrap Icons

### 4. JavaScript Interactivity
- ES6 `const`/`let`
- Functions and arrow functions
- Arrays
- DOM manipulation
- Event handling
- Typing animation
- Dark/light theme switching
- Project filtering
- Animated skill progress bars
- Back-to-top button
- Mobile navbar closing
- Active navigation highlighting

### 5. Validation & Integration
- Client-side form validation
- Required fields
- Email validation
- Minimum message length
- Success/error messages
- Responsive and accessible UI

## How to Run
1. Extract/open the project folder.
2. Open `index.html` in a browser.
3. Internet is required for Bootstrap, Bootstrap Icons and Google Fonts CDN resources.

For GitHub Pages, upload the complete folder to a repository and enable Pages from the repository settings.
